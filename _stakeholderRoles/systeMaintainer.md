## Profile

The System Maintainer is responsible for maintaining the technical infrastructure of the application. This stakeholder ensures that the system remains secure, available, and reliable while supporting continuous operation and software updates.

## Typical Tasks

* Monitor system availability and performance.
* Maintain servers, databases, and technical infrastructure.
* Deploy software updates and security patches.
* Perform backups and disaster recovery procedures.
* Resolve technical issues to ensure reliable system operation.
